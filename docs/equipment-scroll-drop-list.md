# 장비 강화 주문서 드랍처 전체 목록

기준: 현재 V2 장비 강화 주문서 카탈로그와 실제 몬스터/필드보스 드랍 테이블.

- 드랍 확률은 기재하지 않았다.
- 주문서 이름의 `10%`, `60%`, `100%`는 아이템명에 포함된 강화 성공률이다.
- `드랍처 없음`은 아이템은 존재하지만 현재 어떤 몬스터나 보스의 드랍 테이블에도 연결되어 있지 않다는 뜻이다.
- 안전지대 귀환서는 장비 강화 주문서가 아니므로 제외했다.

## 몬스터별 등장 사냥터

- 서류 먼지뭉치: 신입사원 연수원, 결재서류 복도, 파쇄기 문서더미실
- 도망친 스테이플러: 신입사원 연수원, 결재서류 복도, 탕비실 뒷골목, 지하주차장 B1, 스테이플러 수리대
- 커피 얼룩 슬라임: 탕비실 뒷골목, 지하주차장 B1, 옥상 휴게정원, 식은 커피 보관실
- 회의실 생쥐: 옥상 휴게정원, 채용면접 미로, 인재개발원 수련관, 회의실 쥐구멍
- 야근 박쥐: 채용면접 미로, 인재개발원 수련관, 조직문화 기록관, 회계장부 보관실, 야근 박쥐 둥지
- 급여대장 미믹: 조직문화 기록관, 회계장부 보관실, 급여자료 금고, 재무분석 상황실, 브랜드 스튜디오, 야외 광고촬영장, 급여함 미믹 금고
- 감사실 유령: 급여자료 금고, 재무분석 상황실, 감사자료 봉인창고, 브랜드 스튜디오, 야외 광고촬영장, 시장조사 거리
- 광고 카멜레온: 감사자료 봉인창고, 시장조사 거리, 개발팀 스프린트실
- 영업 여우: 개발팀 스프린트실, 서버실 냉각통로, 영업여우 접선로
- 버그 딱정벌레: 서버실 냉각통로, 버그 격리구역, 버그 딱정벌레 둥지
- 서버실 도깨비불: 버그 격리구역, 기업연구소 별관
- 시제품 골렘: 기업연구소 별관, 시제품 실험실, 시제품 골렘 격납고
- 컨베이어 게: 시제품 실험실, 현장직 생산라인
- 품질검사 거미: 사내 데이터센터, 현장직 생산라인, 시설관리 기계실
- 물류창고 멧돼지: 사내 데이터센터, 시설관리 기계실, 품질검사 통제실
- 시설관리 드론: 품질검사 통제실, 야간 물류창고
- 연구동 키메라: 야간 물류창고
- 임원실 사자: 현재 일반 몬스터 등장 사냥터 없음
- 무한야근 사신: 무한야근 심층구역, 출장 준비 빙결통로
- 마감기한 드래곤: 임원 전략회의층, 출장 준비 빙결통로, 마감기한 드래곤 옥상
- 피치전자 게이트 센트리: 무한야근 심층구역, 피치전자 하역장
- 피치 택배 분류봇: 피치전자 하역장, 피치전자 부품창고
- 폭주한 전표 스캐너: 피치전자 부품창고, 피치전자 조립라인 A
- 과열 납땜 드론: 피치전자 조립라인 A, 피치전자 조립라인 B
- 조립라인 근무 로봇: 임원 전략회의층, 피치전자 조립라인 B, 피치전자 품질관리동
- 불량 판정 레이저: 피치전자 품질관리동, 피치전자 회로연구동
- 회로 기판 망령: 피치전자 회로연구동, 피치전자 서버팜
- 임원 경호 안드로이드: 피치전자 임원통제층
- 오버클럭 서버랙: 피치전자 서버팜, 피치전자 임원통제층
- 피치 메인프레임 수호기: 피치전자 중앙코어실
- 야근하다 미쳐버린 황과장: 히든 스트리트 - 미쳐버린 영업 회의실
- 감맘 네오: 히든 스트리트 - 감맘 네오의 폐쇄실
