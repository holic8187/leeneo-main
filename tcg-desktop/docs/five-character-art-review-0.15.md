# 다섯 캐릭터 신규 일러스트 검수 — 0.15

2026-10-20. 사용자가 확인한 ‘깜디’는 기존 검은 고양이 ‘깜둥’으로 적용했다.

## 제작 범위

| 캐릭터 | 신규 등급 | 장수 |
| --- | --- | ---: |
| 구마 | RR, SR, UR, SSR | 4 |
| 깜둥 | RR, SR, HR, UR, SSR | 5 |
| 솜주먹 | R, RRR, SR, HR, UR, SSR | 6 |
| 이지 | R, RR, RRR, SR, HR, UR, SSR | 7 |
| 피치 | R, RR, RRR, SR, HR, UR, SSR | 7 |

총 29장을 개별 이미지로 제작했다. 구마 RR은 주 작업에서 제작했고, 나머지 28장은 아트 보조 작업에서 제작했다. 모든 소비 파일은 `tcg-desktop/public/assets/cards/<card-id>.webp`다. 배포 용량을 줄이기 위해 생성 PNG를 픽셀이 동일한 무손실 WebP로 변환했다. 전체 카드 ID와 장면은 `five-character-art-manifest.json`, 보조 작업의 전체 프롬프트·생성 경로·최종 경로·해시는 `five-character-art-generation-0.15.json`에 기록했다.

## 제작 기준

- 내장 `image_gen`을 자산마다 개별 호출했다. 이미지 시트로 대체하지 않았다. CLI/API 폴백과 Python 이미지 편집은 사용하지 않았다.
- 구마 HR, 깜둥 RRR, 솜주먹 RR, 이지 U, 피치 U의 실제 소비 이미지를 먼저 열어 확인하고 캐릭터 식별 기준으로 삼았다.
- 얼굴, 머리색, 여우/토끼 귀, 동물 털·꼬리·리본 등 캐릭터 특징은 유지했다. 장면, 표정, 동작과 소품은 신규 카드명과 기능에 맞춰 달리했다.
- 낮은 등급은 국소적인 배경과 효과를, 높은 등급은 정교한 환경·복합 효과·영역/차원 현상을 사용했다. SSR은 금색 장식·무지개 빛·큰 공간 규모로 차이를 줬다.
- 인간형은 양팔의 연결, 엄지 방향, 손가락 수와 소품을 쥐는 동작을 확인했다. 동물형은 인간 손을 붙이지 않고 앞발/뒷발과 꼬리 연결을 확인했다.
- 포스터 문구, 카드 프레임, UI를 이미지에 넣지 않았다. 음악 기호·장식 문양·천문 시계 눈금 등 장면에 속하는 표현은 유지했다.

## 검수 결과

29개 명세 파일이 모두 존재하며 최종 WebP 디코딩에 성공했다. 모두 1086×1448 세로 이미지다. 최종 WebP는 생성 PNG와 디코딩 RGBA 픽셀 해시가 동일하다. 보조 작업의 28개 보관 PNG는 선택한 생성 원본과 바이트 단위로 동일하다. 모든 생성 출력의 캐릭터 특징·장면·손/발을 직접 육안 검수했다. 구마 SSR, 깜둥 SSR, 솜주먹 SSR, 이지 SSR은 주 작업에서도 별도로 육안 확인했다.

원본 PNG 29장의 합계는 85,319,386바이트다. PNG 원본은 `tcg-desktop/docs/art-originals-0.15/`에 로컬로 보관하며 빌드 및 Git에 중복 포함하지 않는다. 픽셀이 보존된 WebP는 Git에 보존한다. 전체 변환과 해시 비교 결과는 `card-art-lossless-0.15.json`을 따른다. 화면에 들어가는 카드 프레임과 애니메이션은 기존 렌더러가 별도로 적용한다. 게임 전체 동작·빌드 검증은 주 작업의 회귀 검사 기록을 따른다.
