설계 원칙
- 캐릭터는 고정 직업이 아니라 외형, 성격, 세계관, 연출을 공유하는 테마로 사용한다.
- 실제 역할은 카드 버전별로 정한다.
- 같은 캐릭터의 카드끼리 역할이 겹쳐도 일러스트와 설정에 자연스럽다면 허용한다.
- 같은 캐릭터의 모든 카드가 공격, 회복 등 하나의 역할로만 고정되는 것은 피한다.
- 피해 수치는 카드 공격력 기준, 회복과 보호막 수치는 대상 최대 HP 기준이다.
- 브레이크 게이지는 100을 기준으로 한다.
- 아래 수치와 쿨다운은 3인 파티 턴제 전투를 가정한 밸런스 초안이다.

쿨다운: 4턴
역할: 탱킹·반격

6. 사계의 정원 잔디

쿨다운: 4턴

쿨다운: 5턴

============================================================
캐릭터별 역할 변화 예시
============================================================

겨울
C 회복 → U 방어 → R 브레이크·제어 → RR 탱킹 → RRR 회복·정화 → SR 제어·브레이크 → UR 요새형 탱킹

깜둥
C 탱킹 → U 지원·약화 → R 공격 → RRR 방어·교란

망고
C 공격 → U 방어 → R 공격 → RR 광역 회복 → HR 공격·제어

몬드
C 쿨다운 지원 → U 브레이크 → R 방어·회복 → RRR 복합 지원

구마
C 정화 → U 공격·약화 → R 방어·정화 → RRR 제어·브레이크 → HR 선택형 만능

상해
C 브레이크 → U 탱킹·반격 → R 공격 → RR 탱킹·반격 → SR 마무리 공격

츄밍
C 지원 → R 공격·지원 → RR 공격 지원 → HR 방어·폭발

호이
C 공격·회복 → U 회복·지원 → R 공격 지원 → RR 회복·정비 → RRR 행동 지원 → SR 공격 지원 → UR 선택 지원 → SSR 전략형 복제


추가 메모
- 역할 표기는 검색과 덱 구성에 도움을 주기 위한 주역할이며, 강제 직업 분류가 아니다.
- 캐릭터의 공통점은 속성, 연출, 스킬명, 애니메이션에서 유지한다.
- 강화 +1~+5에 따른 스킬 성장 수치는 전투 기본 규칙과 보스 수치가 확정된 뒤 별도로 조정한다.
- 구형 등급 체계를 사용하는 레거시 카드 8장은 이번 76장 본편 초안에서 제외했다.
