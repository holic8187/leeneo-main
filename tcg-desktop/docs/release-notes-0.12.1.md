# Hoi Card Desk 0.12.1

- 일시적인 서버·네트워크 장애에는 로그인 정보를 유지하고 자동으로 재접속합니다.
- 재접속 중에는 마지막 게임 화면을 가린 상태로 보여주고, 연결이 복구되면 화면·필터·카드 정보창·스크롤 위치를 복원합니다.
- 저장 충돌과 아직 서버에 반영되지 않은 진행 기록을 보존하고, 계정별 화면 복원 정보를 분리합니다.
- 32종의 캐릭터 로딩 이미지를 추가하고 걷기 동작, 크기와 발 위치를 조정했습니다.
- 서버의 초기 데이터베이스 연결 재시도와 장애 응답을 개선해 일시적인 장애가 로그아웃으로 이어지는 문제를 줄였습니다.

앱을 강제 종료한 경우 진행 중인 개인 레이드 전투 자체는 복원되지 않습니다. 마지막 레이드 화면으로 돌아가며, 일반적인 백그라운드 전환에서는 기존 전투를 유지합니다.

검증: 클라이언트 및 서버 자동 테스트. 실제 Android 기기에서의 재접속·업데이트 동작은 별도 확인이 필요합니다.
