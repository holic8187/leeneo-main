# Hoi Card Desk 0.12.0

- 개인·협동 레이드에 자동전투를 추가했습니다. 사용할 수 있는 스킬을 우선하고, 쿨다운·봉인·전투당 사용 제한으로 스킬을 쓸 수 없으면 기본 공격합니다. 회복 대상과 선택형 스킬도 상황에 맞춰 결정합니다.
- 개인 레이드에서 단계를 클리어하면 입장 기회를 1회 추가로 지급합니다. 같은 클리어를 다시 조회하거나 보상 요청을 재시도해도 중복 지급하지 않습니다.
- 레이드 시크릿 모드로 카드 일러스트를 숨길 수 있습니다. 설정은 다음 입장에도 유지됩니다.
- 카드팩 개봉을 한 장씩 넘겨 보는 방식으로 바꿨습니다. 현재 카드 공개, 다음 미공개 카드 이동, 전체 공개를 한 화면에서 사용할 수 있어 히든 카드를 찾아 스크롤할 필요가 없습니다.
- UR 호이의 신생은하가 기록한 행동과 발동 결과를 표시하고, 동률 시 우선할 효과를 선택할 수 있게 했습니다. 선택형 스킬과 SSR 호이의 복제 스킬도 실제 사용한 효과에 맞게 기록합니다.
- UR 겨울의 얼음 첨탑이 광역 공격의 피격 인원 수만큼 소모되던 문제를 수정했습니다. 이제 광역·다단 공격도 보스 공격 행동당 첨탑 1개만 사용하여 피해를 줄이고 한 번 반격합니다. 3턴 후 남은 첨탑은 회복으로 전환됩니다.
- 귤락 7종, 응가 8종, 파이 6종, 월루 8종을 추가해 네 인물 모두 C부터 SSR까지 갖췄습니다. SSR은 각각 공격·지원·지원·방어 역할이며, 신규 스킬은 원래 시전자가 쓰러진 뒤에도 SSR 호이가 복제할 수 있습니다.
- 겨울의 C·R·SR·UR 일러스트에서 손 모양을 교정했습니다. 카드의 능력치와 획득 기록은 바뀌지 않습니다.
- 돌발임무와 관련 알림·설정·보상을 제거했습니다. 기존에 획득한 카드와 재화는 유지되며, 모험 완료 알림은 계속 사용할 수 있습니다.

저장 데이터는 기존 보유 카드·강화·레벨·장비·유물과 진행 중인 모험을 유지합니다. 종료된 돌발임무의 대기 상태와 알림 예약은 정리됩니다.
