# 카드 이미지 무손실 배포 최적화 — 0.15

기존 Android 업데이트 다운로드의 256 MiB 제한에 맞추기 위해 카드 이미지 포장 형식만 변경했다. 그림을 다시 생성하거나 크기를 줄이거나 색을 변경하지 않았다.

- 현재 카탈로그가 참조하던 PNG 98개 중 97개를 Sharp `webp({lossless:true, effort:6})`로 변환했다.
- 각 PNG와 WebP를 RGBA로 디코딩한 뒤 SHA-256을 비교했다. 97개 모두 해상도·채널 수·픽셀 바이트가 동일하다. 개별 결과는 `card-art-lossless-0.15.json`에 보존했다.
- `eungga-c.png`는 유지했다. WebP 인코더가 완전 투명 픽셀 내부의 보이지 않는 RGB를 정리하므로 엄격한 RGBA 일치를 유지하기 위한 예외다. 보이는 픽셀과 알파에는 차이가 없었지만 소비 파일을 바꾸지 않았다.
- 카탈로그의 이미지 확장자만 수정했다. 카드 순서·능력치·스킬·확률은 수정하지 않았다.
- 현재 미사용인 같은 이름의 구형 WebP 13개는 최신 PNG를 덮어쓰지 않도록 별도로 보관했다.

| 항목 | 전 | 후 |
| --- | ---: | ---: |
| 변환한 97개 | PNG 252.93 MiB | WebP 190.18 MiB |
| 전체 카드 소비 폴더 | 277.12 MiB | 210.79 MiB |

카드 폴더에서 총 66.33 MiB를 줄였다. 최종 소비 파일은 카탈로그 169종에 대응하는 169개다. 새로 제작한 29장도 모두 WebP로 소비한다.

PNG 원본 97개와 구형 WebP 13개, 총 110개 256.51 MiB는 `tcg-desktop/docs/art-originals-0.15/`에 **로컬 보관**한다. 해당 폴더는 `public` 밖에 있어 빌드에 포함되지 않으며 Git에도 중복 포함하지 않는다. 픽셀이 동일한 최종 WebP와 변환 검증 기록은 Git에 보존한다. 원본 PNG는 삭제하지 않았다.

이 문서는 카드 자산만의 검증이다. 최종 APK 다운로드 한도 충족 여부는 전체 앱을 다시 빌드한 실제 파일 크기로 확인한다.
