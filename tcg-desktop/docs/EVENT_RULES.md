# 돌발 업무 이벤트 규칙

2026-09-09 개편. 콘텐츠 정의는 `src/data/incidentCatalog.js`, 추첨·선택 검증은 `src/core/incidentEngine.js`에서 관리합니다.

## 개편 전: 0.1.1에서 왜 팝업이 자주 나왔나

이전 구현은 낮은 확률로 이벤트를 발동하는 방식이 아니었습니다. 알림이 켜져 있고 아직 해결하지 않은 이벤트가 없으면, 예약한 시간이 지난 뒤 **반드시 1회** 발생했습니다.

- 예약 시점: 앱 시작, 이벤트 선택지 처리 직후, 설정에서 돌발 업무 알림을 다시 켠 직후.
- 지연 시간: `30,000 + floor(random × 45,000)`밀리초. **30초 이상 75초 미만**, 평균 약 **52.5초**.
- 창을 켜 두었는지, 숨겼는지, 플레이 중인지, 키보드를 사용했는지는 발동 확률에 영향을 주지 않았습니다.
- 종류는 구두 소리, 단체 커피 주문, 수취인 없는 택배, 복합기 고장 **4종**. 매번 같은 확률로 선택하여 **각 25%**였고 연속 중복을 막지 않았습니다.
- 수취인 없는 택배의 봉인 확인을 선택하면 카드팩 1개를 얻었습니다. 해당 이벤트 확률은 25%였으므로, 모든 이벤트를 해결하며 팩 선택지를 고를 경우 평균 4회에 한 번 팩을 받을 수 있었습니다.
- 답을 고르지 않은 활성 이벤트가 있으면 다음 이벤트는 예약되지 않았습니다. 이전 데스크톱 팝업창은 10초 뒤 닫혔지만 활성 이벤트는 게임에 남았습니다.
- 예약 상태는 다음 발생 시각을 저장하지 않았습니다. 앱을 재실행하면 30~75초 타이머를 새로 시작했습니다.

즉시 선택을 끝낸다는 가정에서 최대 처리 빈도의 장기 평균은 시간당 약 **68.6회**였습니다. 실제 빈도에는 사용자의 응답 시간과 앱을 닫은 시간이 추가됩니다.

## 개편 후

| 항목 | 새 규칙 |
| --- | --- |
| 다음 이벤트 대기 | **12~24분**, 평균 **18분** |
| 진행 방식 | 대기 시간이 지나면 1회 발생. 분마다 확률을 굴리지 않음 |
| 발생 조건 | 게임 프로세스가 실행 중이고 알림이 켜져 있으며, 처리 중인 다른 이벤트가 없음 |
| 해결 전 | 활성 이벤트 1개만 유지. 다음 이벤트를 쌓아 두지 않음 |
| 해결 후 | 새 12~24분 대기 시작 |
| 재실행 | 저장된 예약과 다음 발생 시각을 이어서 사용. 종료 중 기한이 지나도 밀린 이벤트 여러 개를 보상하지 않음 |
| 알림 끄기 | 예약 취소. 다시 켜면 새 대기를 시작하고, 이미 도착한 업무는 게임 안에서 처리 가능 |
| 반복 방지 | 최근 도착한 5종을 같은 등급 후보에서 제외 |
| 안전한 보상 | 이벤트 발생 번호와 선택지 ID를 검증. 같은 발생 건은 한 번만 보상 |

즉시 답을 고르는 경우 장기 평균은 시간당 약 **3.3회**로, 이전보다 약 **95% 감소**합니다. 사용자가 답을 고르는 동안 다음 타이머는 진행하지 않으므로 실제 빈도는 더 낮을 수 있습니다. 앱이 완전히 종료된 동안 새 팝업은 표시되지 않습니다.

등급을 먼저 추첨하고 해당 등급 안에서 사건을 고릅니다. 따라서 최근 이벤트 제외 때문에 특수·신화 확률이 높아지지 않습니다.

| 이벤트 등급 | 종류 | 발생 확률 | 최근 이력 없을 때 개별 사건 확률 | 선택 가능한 보상 |
| --- | ---: | ---: | ---: | --- |
| 일반 | 44 | **92%** | 약 2.0909% | 코인 또는 코인+연동 포인트 |
| 특수 | 12 | **7%** | 약 0.5833% | 카드팩 1개 또는 사건별 코인·포인트 |
| 신화 | 4 | **1%** | 0.25% | 카드팩 2개와 일부 추가 보상 또는 큰 코인·포인트 보상 |
| 합계 | **60** | **100%** | — | 모든 사건에 서로 다른 선택지 2개 |

최근 5개에 같은 등급의 사건이 모두 포함된 경우에는 그 등급에서 가장 오래전에 나온 사건을 다시 허용합니다. 현재는 4종인 신화에서만 해당할 수 있습니다. 사건별 확률은 최근 이력에 따라 달라지지만 등급별 92%·7%·1%는 유지됩니다.

특수와 신화를 합친 확률은 **8%**입니다. 팩을 주는 선택지를 항상 고르면 이벤트 1회당 기대 팩 수는 `0.07 × 1 + 0.01 × 2 = 0.09개`입니다. 특정 횟수 안에 등장하거나 팩을 받는다는 보장은 없고, 이벤트에 대한 천장은 없습니다. 코인·연동 포인트 선택지를 고르면 해당 사건의 팩은 지급하지 않습니다. 연동 포인트는 기존 로컬 지갑에 적립되며 외부 계정 지급을 뜻하지 않습니다.
