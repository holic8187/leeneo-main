# 주간 레이드 보상과 카드 성장 변경

## 적용 범위

- 개인 레이드는 한국 시간 월요일 00:00에 마감하며, 서버가 최종 합산 피해 순위에 따라 우편을 보낸다.
- 보상 적용은 **2026-10-19 시작 주간**부터다. 첫 정산 시각은 **2026-10-26 00:00 KST**이며 그보다 오래된 기록은 소급 지급하지 않는다.
- 서버는 시작 시와 매 1분마다 미정산 기록을 확인한다. 오프라인 계정에도 지급되며, 서버 중단 기간의 미지급분은 재시작 후 처리된다. 우편함을 열 때도 해당 계정의 미지급분을 확인한다.
- 점수 0점은 제외한다. 동점은 공동 순위로 같은 보상을 받으며, 다음 순위는 공동 순위 인원만큼 건너뛴다. 예: 1위, 1위, 3위.

## 보상표

| 최종 순위 | 보상 |
| --- | --- |
| 1–2위 | SR 이상 확정 카드팩 5개 |
| 3–4위 | SR 이상 확정 카드팩 4개 |
| 5–6위 | SR 이상 확정 카드팩 3개 |
| 7–8위 | SR 이상 확정 카드팩 2개 |
| 9–10위 | SR 이상 확정 카드팩 1개 |
| 11–30위 | 고급 카드팩 3개 + 6,000코인 |
| 31–100위 | 고급 카드팩 2개 + 3,000코인 |
| 101위 이하 참여자 | 표준 카드팩 2개 + 1,000코인 |

SR 이상 확정 카드팩은 `packs.srPremium`에 보관하며 우편 보상 필드는 `srPremiumPacks`다. 우편은 발송일부터 30일 동안 수령할 수 있다. 보상표는 `src/data/weeklyRankingRewards.json`을 서버와 클라이언트가 함께 사용한다.

## 중복 지급·저장 보호

마감된 주간의 모든 점수를 먼저 동결한다. 레이드 입장/결과 저장은 동결 여부를 같은 원자적 갱신 조건으로 검사하므로 마감 직전 시작된 요청이 지급 순위를 뒤늦게 바꿀 수 없다.

우편 추가와 계정별 지급 영수증은 하나의 계정 문서에 함께 기록한다. 발송 후 서버가 중단되거나 우편이 수령·삭제된 다음 재시도되어도 같은 주간 보상을 다시 보내지 않는다. 계정 우편함의 미수령 우편이 200개로 가득 찼다면 지급을 보류하며 영수증을 소비하지 않는다. 공간을 확보하고 우편함을 열면 다시 시도한다. 다른 계정의 보상은 계속 처리한다.

구버전 클라이언트가 저장할 때 신규 팩 필드를 누락하더라도 서버는 기존 SR 이상 확정 카드팩 수량을 유지한다. 저장 버전 검사를 통해 오래된 저장본이 최신 보상을 덮어쓸 수 없다.

## 협동 보상과 레벨

- 협동 레이드 승리 시 각 참가자는 단계와 무관하게 **0.5%**의 독립 확률로 SSR 확정 랜덤 뽑기권 1개를 추가 획득한다. 다른 드롭과 함께 나올 수 있으며 패배 위로금에는 적용되지 않는다. 추첨 결과는 전투 종료 시 서버에 보관하고 기존 보상 영수증과 함께 한 번만 수령한다.
- 공격 역할 카드의 레벨당 공격력 증가는 **2 → 8**이다. 레벨 1은 추가 공격력 0, 레벨 11은 +80, 레벨 100은 +792다.
- 기존 카드도 저장된 레벨에서 즉시 다시 계산한다. 경험치·강화 단계·보유량을 재작성하지 않는다. 방어/지원 역할의 기존 성장량은 동일하다.
- 개인 레이드 서버 검증, 협동 레이드 서버 전투, 모험 및 클라이언트 표시가 같은 성장량을 사용한다.
