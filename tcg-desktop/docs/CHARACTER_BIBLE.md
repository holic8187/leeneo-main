# 캐릭터 바이블

## 공통 원칙

한 캐릭터의 등급별 카드는 동일 인물로 즉시 알아볼 수 있어야 한다. 얼굴과 체형, 대표 색, 기본 의상, 귀·꼬리·뿔 같은 실루엣, 고정 동료를 유지한다. 상위 등급에서는 배경의 규모, 조명, 행동과 마법 효과를 키우고, 표정·시선·손동작·카메라 구도를 의도적으로 바꿔 같은 포즈의 반복을 피한다. C는 배경 없는 단독 캐릭터 컷으로 시작하며, U 이상부터 장면을 확장한다.

참조 이미지가 여러 캐릭터를 담은 시트이므로 생성할 때 반드시 `characterId`, 아래 외형 설명, 매니페스트의 장면을 함께 사용한다. 시트의 다른 캐릭터나 글자를 결과물에 섞지 않는다.
