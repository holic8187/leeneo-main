호이 카드 데스크 0.11.0 — 모래 / 실시간 협동 레이드 초안 및 구현 규칙
작성일: 2026-09-30

1. 입장과 자동 편성
- 협동 전용 보스: 사중공명체 테트라.
- 각 계정은 보유 중이며 모험에 사용하지 않는 서로 다른 인물의 대표 카드 3장을 등록한다.
- 같은 인물의 다른 등급은 대표 카드에 중복 등록할 수 없다.
- 4명의 대표 카드에서 각자 1장씩 선택하고, 최종 4장의 인물도 모두 달라야 한다.
- 자동 편성은 최대 81가지 카드 조합을 비교한다. 방어/공격/지원 역할의 다양성을 먼저,
  다음으로 합산 공격력을 우선한다. 동점은 무작위다. 외부 생성형 AI 호출은 사용하지 않는다.
- 4명 모두 같은 세 인물만 등록한 경우처럼 가능한 조합이 없으면 다음 참가자를 기다린다.
- 매칭되면 어느 화면에 있든 30초 입장 팝업을 표시한다. 모두 확인해야 출발한다.
- 시간 내 미확인자는 탈퇴하고, 확인한 사람은 원래 대기 우선순위를 유지해 재대기한다.
- 한국 시간 00:00에 초기화되는 하루 2회. 전원 입장 확정 때 한 번만 차감한다.
- 카드 선택은 클라우드의 소유/강화/레벨로 검증하고 입장 직전 재검사한다.
- 카드 1장씩만 출전한다. 이번 초안에서는 장비와 유물의 능력치는 협동 전투에 적용하지 않는다.

2. 전투
- 네 카드의 행동 순서는 서버에서 한 번 무작위로 정하고 저장한다.
- 기본 공격 / 고유 스킬 / 대상 선택. 개인 레이드와 같은 7라운드, 아군-보스 교대 규칙.
- 전투불능 카드는 즉시 건너뛰며 빈 슬롯 때문에 보스 행동을 추가하지 않는다.
- 각 행동 제한 20초. 무응답 또는 연결 끊김은 서버가 기본 공격으로 처리한다.
- 서버가 전투 상태와 난수 상태를 저장한다. 클라이언트가 보낸 피해량은 사용하지 않는다.
- 전투 상태는 약 1초마다 동기화한다. 서버 재시작 후에도 저장한 제한시간부터 진행을 복구한다.
- 대기/전투 중 강화, 합성, 레벨업, 모험 출발, 개인 레이드 시작은 화면에서 제한한다.

3. 난이도
- 도달 단계는 각 참가자의 서버에 저장된 현재 주간 개인 레이드 단계(1~10)다.
- 네 사람의 단계 합 S는 4~40, 보스 최대 HP = S × 12,500 (50,000~500,000).
- 기본 피해 = 8 + S × 0.25. 사용 패턴 수 = 2 + floor((S-4)/9).
- 합 4: 사중 공명파, 붕괴 예고.
- 합 13: 삼색 위상막 추가. 합 22: 잔향 역류 추가.
- 합 31: 결계 조율 추가. 합 40: 엇갈린 파장 추가.
- C 조합 200개 난수/순서 표본으로 최저 난도 검토: 균형 조합은 클리어 가능,
  다른 조합은 시간 초과도 발생한다. 이 수치는 출시 초안으로 실제 플레이에 따라 조정 가능하다.

4. 전용 패턴과 대응
- 사중 공명파: 전체 피해를 생존 아군 수로 나눈다. 전원 생존 유지가 유리하다.
- 붕괴 예고: 최고 공격력 아군을 표시하고 다음 보스 행동에 폭발. 그 전에 브레이크로 취소.
- 삼색 위상막: 받는 피해 40% 감소. 서로 다른 3명의 공격 또는 브레이크로 해제.
- 잔향 역류: 직전 아군이 스킬을 썼다면 추가 피해. 기본 공격 선택으로 증폭을 피할 수 있다.
- 결계 조율: 각 아군 보호막의 30%를 흡수해 보스 보호막으로 변환한 후 공격.
  남은 아군 보호막은 평소처럼 피해를 흡수한다.
- 엇갈린 파장: 서로 다른 두 아군에게 피해량 감소 / 받는 회복량 감소를 각각 부여.
  정화, 약화 차단, 저항, 모래 HR의 예비정화로 대응할 수 있다.

5. 보상 (참가자별 독립 추첨)
- 승리: 동전 S×500, 카드팩 ceil(S/4).
- S≥24: SR 이상 인물 카드 1장 확정. 등급 가중치 SR70 / HR22 / UR7 / SSR1.
- 유물: 0.1% + 0.9%×(S-4)/36. 성공 시 현재 유물 목록에서 무작위 1장.
  현재 출시된 유물은 명품 가방 1종이다.
- 장비 등장: 15% + 35%×(S-4)/36. 무기/방어구 50:50, 이후 등급을 추첨한다.
- 장비 품질은 난이도에 비례한다. SSR은 장비 등장 후 등급 추첨에서 0.01%다.
- 장비 능력치/±10% 편차/소수 첫째 자리 표시는 모험 장비와 동일하다.
- 패배: 승리 동전의 10%, 카드팩/희귀 보상 없음.
- 실제 출전한 대표 카드에 개인 레이드와 같은 경험치 공식을 적용한다. 승리/패배 모두 지급.
- 보상은 서버에서 한 번 결정해 영구 보관한다. 수령 시 재화, 카드, 장비, 유물, 경험치와
  서버 전용 수령 기록을 같은 저장 작업으로 반영한다. 응답 유실/재접속/중복 요청에도 중복 지급하지 않는다.
- 미수령 완료 전투는 별도 보관하여 다른 플레이어의 대기열을 막지 않는다.

6. 모래 신규 카드 (기존 C/U/R 유지, 기존 다른 카드 능력치 유지)
RR 협곡의 푸른 피난처: 방어, 전체 보호막 + 지속 피해 감소.
RRR 유리사막의 천공자: 공격, 공격/브레이크 + 남은 보스 보호막 추가 제거.
SR 별우물의 인도자: 지원, 전체 회복/정화 + 보스 공격력 감소.
HR 새벽 오아시스의 파수꾼: 지원, 강한 아군 둘 보호막 + 피격 후 예비정화.
UR 사막천궁의 수호자: 방어, 전체 보호막 + 보호막 파괴 후 생존자 회복.
SSR 불침의 푸른 사막왕: 방어, 전체 보호막 + 다음 3회 피해 감소 + 저장 피해 반격.
- SSR 호이가 복제해도 효과 수치를 85%로 한 번만 적용하고 원본 전투불능 이후 유지한다.
- 호이의 파티 회복/보호막 복제 시 본인 몫이 사라질 수 있던 문제도 함께 수정했다.

7. 배포 전 검증 범위
- 자동 편성, 조합 불가, 소유 카드 검증, 단계/피해 위조 무시.
- 동시 입장, 30초 만료, 재접속, 자동 행동, 본인 차례, 자정 요청 역전.
- 보상 중복 방지, 보상 저장 후 응답 유실, 완료 전투 보관, 경험치 중복 방지.
- 모래 6종 정상/복제, 전투불능 후 지속 효과, 새 보스 6개 패턴.
- 실제 main 화면 360×800 / 390×844 / 1280×900에서 모의 서버 UI 흐름 검증.
- 웹 production build, Android 동기화 및 실제 Gradle APK 컴파일.
- 실제 로컬 MongoDB 8.0.10에서 4인 동시 입장, Mongoose CAS, 보상 중복 방지,
  완료 전투 보관 및 서비스 재생성 후 복구 검증. 임시 테스트 DB만 사용 후 삭제.
- 외부 사용자 네 명의 실기기 네트워크 플레이는 배포 후 별도 운영 확인 대상이다.

8. 운영 메모
- MongoDB tcg_cooperative_raids에 원자적 CAS 코디네이터 및 불변 완료 전투를 보관한다.
- 대기열 최대 128명, 동시에 입장 확인/전투 최대 64개. 빈자리 발생 시 다음 요청에서 매칭.
- 서버 전용 TcgPlayerState.cooperativeRewardClaims는 일반 클라우드 저장으로 덮어쓰지 않는다.
- API: GET /api/tcg/raids/cooperative/state,
  POST /queue, /leave, /accept, /action, /claim (공통 접두 경로 동일).
- 읽기는 인증 필요, 변경은 활성 플레이 연결 검증. 보상 수령은 저장 revision 추가 검증.
- 새 파일과 기존 문서에 저장한 일러스트 원본 및 최종 프롬프트는 아트 manifest JSON 참조.
