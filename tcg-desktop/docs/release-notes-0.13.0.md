# Hoi Card Desk 0.13.0

## 카드와 카드팩

- 고급 카드팩: 15,000코인, 1팩 5장, 모든 카드 RR 이상. 1팩·10팩 개봉 지원.
- 고급팩 1장당 등급 확률: RR 62.5%, RRR 25%, SR 8.75%, HR 2.75%, UR 0.875%, SSR 0.125%. 표준팩의 기본 RR 이상 확률 비율을 환산하며 별도 천장은 적용하지 않습니다.
- 겨울·난체·츄밍의 빠진 등급 14종을 추가하여 세 인물 모두 C/U/R/RR/RRR/SR/HR/UR/SSR을 갖춥니다. 각 카드는 새 원화, 고유 스킬, 강화 수치, 역할을 갖습니다.
- 수집 가능한 카드는 총 132종입니다.
- 응가 9등급 원화와 재접속 로딩 캐릭터를 금빛 왕관을 쓴 둥근 갈색 봉제 정령으로 변경합니다. 기존 보유 카드, 전투력, 강화·레벨은 유지됩니다.
- 확정 SSR 랜덤 뽑기권: 운영자 우편 지급 전용. 현재 SSR 10종 중 각 10%로 1장을 획득합니다. 상점 판매 없음.
- 중복 획득은 상단 텍스트로 묶어 표시합니다. 처음 얻은 카드 또는 SR 이상만 뒷면으로 표시하며 좌우 넘기기, 개별 공개, 모두 뒤집기를 지원합니다. 같은 카드의 미공개 결과를 중복 요약이 미리 알려주지 않습니다.
- 미공개 결과와 뒤집은 상태를 저장하여 다른 창을 열거나 재접속해도 이어봅니다.

| 인물 | 추가 등급 |
| --- | --- |
| 겨울 | HR, SSR |
| 난체 | R, RR, RRR, SR, HR, UR, SSR |
| 츄밍 | U, RRR, SR, UR, SSR |

## 전투

- UR 겨울 얼음 기둥 3개를 실제 전장에 표시하고 생성·파괴·소멸을 각각 연출합니다. 복제된 기둥도 구분해 표시합니다.
- SSR 코카 저장 공격, UR 호이 은하수 등 조건부 후속 효과는 조건을 충족한 아군 행동 후 별도 자동 행동으로 발동한 뒤 보스에게 넘어갑니다. 정규 행동 횟수·쿨다운을 추가 소비하지 않습니다.
- 복제된 지속 지원 효과의 원래 강화 수치와 복제 배율을 유지하고, 반격에 강화 수치가 중복 적용되던 계산을 수정합니다.
- 협동 대표 카드 3장을 고른 직후 서버 조회 때문에 확인 버튼이 비활성으로 남던 문제를 수정합니다.
- 개인·협동 레이드는 같은 전투 화면을 사용합니다. 행동 카드 강조, 돌진·피격, 스킬 확대 연출, 상태 아이콘·설명, 브레이크·스턴, 월루 모드를 공통으로 표시합니다.

## 운영 및 저장

- 관리자 개별·전체 우편에서 고급 카드팩과 SSR 뽑기권의 수량을 지정할 수 있습니다.
- 저장 형식은 v11입니다. 구 저장의 고급팩·SSR권은 0으로 시작하며, 기존 재화·카드·개봉 기록은 보존됩니다.
- 클라이언트와 서버를 함께 배포해야 신규 우편 지급 및 협동 후속 행동이 제공됩니다. 이 문서는 배포 완료를 의미하지 않습니다.
