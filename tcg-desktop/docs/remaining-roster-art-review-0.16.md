각 카드는 내장 image_gen으로 독립 생성했습니다. 스프라이트 시트나 기존 그림 복사로 대체하지 않았습니다. 기존 C·상위 등급 참조를 직접 확인해 얼굴, 체형, 의상, 동물 특징을 유지하면서 등급별 상황·표정·소품·구도를 달리했습니다. U는 소박한 일상 장면, R/RR은 작은 효과와 명료한 상황, RRR/SR은 겹친 배경과 마법, HR은 큰 무대, UR은 공간·시간 현상, SSR은 무지개·금빛의 장대한 장면으로 구성했습니다.

생성 결과를 모두 육안으로 확인해 인물 식별성, 손과 손목 연결, 소품 잡는 자세, 동물 발·다리, 화면 내 주인공의 가독성을 점검했습니다. 라연이의 부채·그릇·거울, 몬드의 지도·컴퍼스·밧줄, 상해의 검과 검집, 각 동물의 앞발과 뒷발을 확인했습니다. 최종 U 3장은 별도 담당자의 검수 후 다시 확인했습니다.

최종 소비 파일은 `public/assets/cards/{id}.webp`이며 전부 1086×1448입니다. Sharp의 lossless WebP 포장만 적용했고 리사이즈나 손실 압축은 하지 않았습니다. PNG와 WebP를 각각 RGBA로 디코딩해 55장 모두 바이트 단위 동일성을 확인하고 SHA-256을 기록했습니다. 원본 PNG 합계 149.55 MiB, 최종 WebP 합계 111.80 MiB로 37.76 MiB 줄었습니다.
