# 카드 일러스트 전수 검토 — 2026-09-22

## 범위와 기준

메인 카드 83장, 이전 버전 카드 8장(총 91장), 명품 가방 유물 1장, 레이드 배경과 앱 아이콘을 확인했다. 전체 목록을 12장씩 렌더링한 검토 보드로 훑고 손·귀·발·도구·반사가 의심되는 카드는 원본 크기로 확대했다. 새 코카 7종은 개별 원본도 모두 확인했다.

사람의 손가락과 손목 연결, 동물의 중복 귀/사지, 무기와 손의 접촉, 장신구 연속성, 수면 반사, 소품 구조, 등급별 연출을 기준으로 검토했다. 가림과 원근법, 설정상 비인간형 손/발은 오류로 단정하지 않았다. 눈으로 검토한 결과이며 모든 미세한 그림 오류가 없다는 자동 보증은 아니다.

## 유지한 스타일

- 호이의 별빛 리본형 긴 부속은 여러 등급에서 일관된 디자인이어서 귀로 오인해 제거하지 않았다.
- 감맘 네오의 감자형 손, 상해 SR의 상어형 손, 솜주먹의 솜뭉치 주먹은 비인간형 캐릭터 표현으로 유지했다.
- 가려진 손가락이나 의복에 가린 다리는 실제 중복/융합이 확인되지 않으면 변경하지 않았다.
- 모바일에서 강화(+0~+5)와 역할 아이콘은 일러스트와 분리된 SVG로 표시한다.

## 재검토 방법

`scripts/review-card-art.mjs`는 로컬 개발 서버의 현재 카탈로그와 유물을 읽어 검토 보드를 만든다. 생성된 원본을 변형하지 않는 브라우저 렌더링이다. 카드 경로 존재 여부는 게임 테스트로, 320/390px와 PC 화면은 `scripts/check-loadout-ui.mjs`로 확인한다.

기능 변경과 함께 수행한 회귀 검증 및 최종 테스트 결과는 작업 완료 보고를 참고한다. 현재 변경분은 로컬 작업 트리에 적용했으며, 이 검토 자체가 APK/EXE 또는 서버 공개 배포를 의미하지 않는다.
