# Hoi Card Desk 0.10.0

- 완료한 모험을 같은 카드·장비·유물 편성으로 다시 보낼 수 있습니다.
- 레이드 5~10단계 클리어에 유물 획득 확률을 추가했습니다(0.5/1/1.5/2/2.5/3%). 8~10단계는 SR 이상 카드 1장을 추가로 보장합니다.
- 첫 유물 ‘명품 가방’을 추가했습니다. 장착하고 출발한 모험의 재화 보상이 5% 증가합니다. 장비 탭에서 선택하고 공유 프리셋에 저장할 수 있습니다.
- 코카 U/RR/RRR/SR/HR/UR/SSR 7종과 고유 스킬을 추가했습니다. SSR 코카는 공격 역할이며 아군 3명의 공격을 모아 추가 피해를 주는 스킬을 사용합니다.
- 카드 그림 오른쪽 위에 강화 +0~+5, 왼쪽 아래에 공격·방어·지원 아이콘을 표시합니다.
- 코카 오로라의 반사 목걸이를 포함해 일러스트 11장의 귀·손·도구·장신구를 교정했습니다.
- SSR 호이의 신규 코카 스킬 복제, 연계 피해의 재귀 발동, 보스 처치 후 0 피해 연출을 수정했습니다.
- 구버전과 신버전 기기를 번갈아 사용할 때 레이드 추가 보상이 중복 지급되는 문제를 방지했습니다. 기존 보유 카드·강화·레벨은 유지됩니다.

클라이언트 227개와 서버 44개 테스트, 웹 빌드 및 PC·모바일 390px·320px 화면 검증을 통과했습니다. 실제 기기별 설치·알림 권한 동작은 별도 확인이 필요합니다.
