# 모험 재출발·유물·코카 업데이트

공개 배포 전 로컬 작업 기록이다. 기존 0.9.2 APK/EXE 다운로드에는 이 변경분이 포함되어 있지 않다.

## 반영 내용

- 모험 완료 결과창과 모험 화면에서 같은 모험을 다시 보낼 수 있다. 이전 카드 순서·장비·유물을 사용하되, 현재 보유 여부와 현재 전투력을 다시 검사한다. 이미 진행 중인 모험은 중복 시작하지 않는다.
- 레이드 클리어 시 유물 획득 확률은 5/6/7/8/9/10단계에서 각각 0.5/1/1.5/2/2.5/3%다. 첫 유물만 출시된 현재는 성공 시 명품 가방을 획득한다.
- 레이드 8~10단계 클리어마다 SR 이상 카드 1장을 추가 지급한다. 기본 카드팩 보상은 유지한다. 서버가 추첨 결과를 저장하므로 완료 요청을 재전송해도 다시 추첨하지 않는다.
- 명품 가방을 모험 출발 시 장착하면 최종 재화 보상에 5%를 추가한다. 정수 단위로 반올림하며 카드팩·장비·경험치는 늘리지 않는다. 여러 장 보유해도 효과는 중첩되지 않는다.
- 카드/장비 두 탭 구조를 유지하고, 장비 탭 아래에 유물 선택 영역을 배치했다. 모험·레이드·공유 프리셋에서 선택과 저장이 가능하다. 명품 가방 자체에는 레이드 전투 효과가 없다.
- 코카 U/RR/RRR/SR/HR/UR/SSR 7종을 추가했다. 원래 C/R 카드와 기존 카드 ID·전투력은 유지한다. 그림은 등급마다 표정·구도·배경을 구분했다.
- SSR 코카는 공격 역할이다. 스킬 사용 후 서로 다른 아군 3명의 주 공격 피해 일부를 모아 추가 피해를 주는 효과를 갖는다. 원본 사용자가 쓰러진 뒤 SSR 호이가 복제해도 복제 효과가 유지된다.
- 강화 +0~+5 표시는 오른쪽 위, 공격/방어/지원 아이콘은 왼쪽 아래에 적용했다. +5는 무지개색이며 역할 아이콘은 빨간 검/파란 방패/초록 십자가다.

## 추가 수정

- 씨앗·별빛·호랑이 계열 연계 피해가 서로를 재호출하는 문제를 차단했다. 추가 피해는 다른 추가 피해를 재귀적으로 발동하지 않는다.
- 보스가 쓰러진 뒤 이어지는 0 피해·브레이크 연출을 차단했다.
- 레이드 추가 카드 획득은 기존 강화 수치와 레벨을 유지하고 새 기본 강화 복사본만 추가한다.
- 추가 보상 수령 기록을 구버전에서도 보존하는 별도 저장 항목으로 관리한다. 신버전에서 획득한 뒤 0.9.2 기기에서 저장하고 돌아와도 같은 카드·유물을 다시 지급하지 않는다. 기존 중첩 수령 기록은 합산 이관하고, 실제 미수령 보상은 그대로 지급한다.
- 일러스트 91장, 유물 1장, 배경과 앱 아이콘을 검토했다. 11장 수정 내용과 복구용 원본 보존 방식은 [일러스트 검토 기록](art-review-2026-09-22.md)에 정리했다.

## 검증 범위

- 클라이언트 전체 테스트와 서버 TCG 테스트, 웹 프로덕션 빌드.
- 모의 계정으로 PC 1440px, 모바일 390px 및 320px 화면에서 완료 후 재출발, 프리셋 저장/불러오기, 유물 선택, 아이콘 표시, 전투력/인원 제한 검증.
- 서버의 유물 확률 경계·SR 이상 보장·중복 완료 요청 및 클라이언트 보상 재수령 방지 검증.
- 실제 Android 기기와 새로운 APK/EXE 패키지 실행은 이번 검증 범위에 포함하지 않는다. 공개 적용에는 서버와 클라이언트의 새 버전 배포가 필요하다.
