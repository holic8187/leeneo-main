# 0.15.0 작업 기록

작업일: 2026-10-20. 이번 변경은 `codex/tcg-rewards-roster-ui-0.15.0` 브랜치에서 준비했으며, 사용자 요청에 따라 기존 PR #20에 통합하여 PC·Android 및 운영 서버에 배포한다. 기존 0.14.0 팝업 유지·iOS 준비 작업도 함께 포함한다.

## 보상과 성장

- 협동 레이드 클리어 시 참가자마다 독립적인 0.5% 확률로 SSR 확정 랜덤 뽑기권 1장을 추가 지급한다. 패배 보상에는 적용하지 않는다.
- 공격 역할의 레벨당 공격력 증가량을 +2에서 +8로 변경한다. 기존 카드도 현재 레벨에 따라 즉시 재계산한다. Lv.100의 추가 공격력은 +792다.
- 개인 레이드 주간 랭킹 1~2위 5팩, 3~4위 4팩, 5~6위 3팩, 7~8위 2팩, 9~10위 1팩을 지급한다. 모두 SR 이상 확정 카드팩이다.
- 11~30위 고급 3팩+6,000코인, 31~100위 고급 2팩+3,000코인, 101위 이후 점수가 있는 참여자 표준 2팩+1,000코인이다.
- SR 이상 확정 팩은 5장 구성이고 카드별 확률은 SR 70%, HR 22%, UR 7%, SSR 1%다.
- 한국 시간 월요일 00시에 순위를 마감하며 우편으로 지급한다. 동점은 공동 순위로 같은 보상을 받는다. 우편 수령 기한은 30일이다. 보상 적용 주간은 2026-10-19부터, 첫 정산은 2026-10-26 00시다.
- 서버 재시작·오프라인·우편함 포화 시 지급을 재시도하며, 지급 영수증으로 중복 발송을 막는다. 구버전 저장에서 신규 팩 필드가 빠져도 기존 수량을 보존한다.

## 신규 카드와 일러스트

구마·깜둥·솜주먹·이지·피치의 비어 있던 등급을 총 29장 추가하여 다섯 인물 모두 C~SSR 전 등급을 갖춘다. 정규 도감은 161종이며 SSR은 15종이다. 기존 인물의 모습을 유지하면서 등급별 상황·표정·구도·배경 밀도를 달리 제작했다.

| 인물 | 추가 등급 | UR·SSR의 주요 기믹 |
| --- | --- | --- |
| 구마 | RR, SR, UR, SSR | 약화를 보호막과 브레이크로 환전 / 실제 잃은 HP를 장부에 모아 추가 공격 |
| 깜둥 | RR, SR, HR, UR, SSR | 가장 위태로운 아군의 그림자 대역과 추격 / 보스 강화 약탈 |
| 솜주먹 | R, RRR, SR, HR, UR, SSR | 흡수한 보호막을 다음 아군에게 전달 / 다른 아군의 보호막을 필요한 만큼 공유 |
| 이지 | R, RR, RRR, SR, HR, UR, SSR | 기본 공격과 스킬의 교차 리듬에 추가 효과 / 기록한 HP로 되감기 |
| 피치 | R, RR, RRR, SR, HR, UR, SSR | 필요할 때까지 자라는 예약 회복 / 생존 아군 HP 비율 재분배 |

모든 신규 효과는 강화 수치, 복제, 개인·협동 전투, 상태 아이콘과 연결했다. 조건부 공격은 기존 추가 행동 구간을 거친다. 스턴으로 건너뛴 보스 행동은 효과 횟수를 소비하지 않으며, 빗나간 직접 공격은 공격 행동으로 집계한다.

신규 29장의 스킬명·효과·쿨타임은 `신규카드_스킬_0.15.0.txt`에서도 확인할 수 있다.

츄밍은 전 등급 9장을 육안 점검했다. C/R/RR/RRR/HR/SSR 6장을 손·손목·팔 방향에 맞춰 다시 제작했고 U/SR/UR은 유지했다. 자세한 생성 기록은 `chuming-hand-audit-0.15.md`, 신규 카드 기록은 `five-character-art-generation-0.15.json`에 있다.

## 화면 개편

- 대표 카드, 모험·레이드 진입, 미확인 카드 이어보기를 전면에 배치했다.
- 카드 소환을 독립 메뉴로 모으고 일반·고급·주간 보상팩과 SSR 뽑기권을 함께 확인하게 했다.
- 남색·금색 프레임과 밝은 내용 패널로 전체 메뉴·버튼·정보창의 시각 체계를 맞췄다.
- PC는 좌측 메뉴, 모바일은 하단 7개 메뉴를 제공한다. 창 크기에 따라 배치를 조정하고 기존 독립 스크롤을 유지한다.
- 주간 보상 안내와 활동 기록은 자동 갱신 후에도 펼침 상태를 유지한다. 월루모드에서도 대표 카드의 등급·이름·능력치를 확인할 수 있다.

참고 작품은 사용자가 확인한 **소프트맥스 이너월드 시즌 2**만 사용했다. 다른 게임의 인터페이스는 참조하지 않았다.

- 화면 구조 자료: https://www.gamemeca.com/view.php?gid=303007
- 시즌 2 자료: https://www.inven.co.kr/webzine/news/?news=100526

## 검증 기록

- 클라이언트 전체 검사: **398/398 통과**, 서버 TCG 검사: **84/84 통과**.
- 실제 보스 1~10단계를 각 20전씩, 혼합 덱 총 **200전** 자동 진행. 신규 29종 스킬 사용과 SSR 호이의 신규 23종 스킬 복제를 확인했다. 8,213개 전투 상태에서 수치·쿨다운·저장 복원·추가 행동 종료 검사 통과.
- 40전 클리어, 45전 전멸, 115전 7턴 종료. 모든 전투가 종료되고 추가 행동 무한 반복은 없었다.
- 신규 29장(각 1086×1448)과 츄밍 9장의 이미지 디코딩·경로 검증 통과. 손 검수는 육안으로 수행했다.
- 카드 97장과 보스·배경·유물 3장을 무손실 WebP로 변환하고 원본과 디코딩한 RGBA 해시가 완전히 같음을 확인했다. 카드 폴더는 중복 제거까지 66.33 MiB, 보스·배경·유물은 2.13 MiB를 줄였다. 로딩 이미지 32장은 12.59 MiB를 줄였으며 모든 보이는 픽셀과 알파값이 같다. 완전 투명 영역의 숨겨진 RGB만 정규화했다. 원본 PNG는 로컬 `docs/art-originals-0.15/`에 별도 보관하며 설치 파일과 저장소에는 중복 포함하지 않는다.
- 운영 계정과 분리된 로컬 시험 서버에서 320×568, 390×844, 768×600, 1280×720 화면을 확인했다. 소환·주간 보상·월루모드·정보창·갱신 후 펼침 상태를 검증했다.
- 업데이트 전 저장된 개인·협동 전투, 버프 원본, 추가 행동과 스킬 연출의 이미지 경로도 현행 자산으로 연결한다. 저장된 전투 수치는 바꾸지 않는다.
- Android 운영 API 빌드 및 버전 0.15.0/code 15000 검증 통과. unsigned release APK 250.91 MiB로 기존 앱의 256 MiB 다운로드 제한을 통과했다. 공개 CI에서 동일 서명키로 서명하고 최종 크기를 다시 검사한다. 실제 휴대폰 설치 검사는 이 작업에서 수행하지 않았다.
